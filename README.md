# Практична робота №2. Робота з базою даних: об'єктно-реляційне відображення та міграції схеми

**Виконав:** Черкасов Ілля  
**Стек:** Python 3.14, Django ORM, SQLite/PostgreSQL  

## Опис проекту
У рамках практичної роботи реалізовано шар доступу до даних (Data Access Layer) для предметної області **"Бібліотека"** із застосуванням паттерну **Repository**.

### Основні сутності:
* **`Author` (Автор):** зберігає ім'я, прізвище та унікальний Email.
* **`Book` (Книга):** зберігає назву, опис, дату публікації, кількість сторінок, ціну та зовнішній ключ `author` з обмеженням `RESTRICT`.

## Реалізовано:
- [x] Опис моделей Django ORM з обмеженнями полів (`max_length`, `unique`, `RESTRICT`).
- [x] Генерація та застосування міграцій схеми БД.
- [x] Реалізація CRUD-операцій через окремий `BookRepository`.
- [x] Оптимізація запитів за допомогою `select_related` (аналог `Include`).
